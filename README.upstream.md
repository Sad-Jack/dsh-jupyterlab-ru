# dsh-jupyterlab

[![Лицензия](https://img.shields.io/badge/license-MIT-blue.svg)](./LICENSE)

**Блокнот в стиле JupyterLab для DeepSeek Harness.** Настоящее постоянное ядро `ipykernel`, которое агент может читать, редактировать и выполнять. Интерфейс: код слева, графики справа, сочетания клавиш Jupyter и Markdown-ячейки.

> **Изменённый форк [`@beihaizb/dsh-notebook`](https://github.com/beihzb/dsh-notebook) автора beihzb, лицензия MIT.**
> Процесс ядра, инструменты агента `nb_*`, чтение/сохранение `.ipynb` и интерфейс ячеек созданы в исходном проекте. Форк сохраняет их и добавляет перечисленные ниже возможности одним самостоятельным плагином. Исходники включены в пакет, поэтому `dsh plugin add` устанавливает весь необходимый код плагина.

## Дополнения форка

1. **Раздельное представление «код | результат».** Редактор слева, графики, stdout, DataFrame и трассировки справа. Разделитель перетаскивается, пропорция запоминается. Переключатель, в исходнике `⇔ Split` / `⇕ Inline`, возвращает обычное вертикальное расположение.
2. **Результат остаётся видимым.** Область вывода выровнена снизу и удерживается в видимой части окна при прокрутке длинной ячейки: свежий график не остаётся за пределами экрана в её начале.
3. **Клавиши Jupyter.** `Esc` выводит из редактирования в командный режим; `a` / `b` добавляют ячейку выше/ниже, `dd` удаляет, `Enter` редактирует, `↑` `↓` либо `k` `j` перемещают выбор, `m` / `y` выбирают Markdown/код. `Ctrl+Enter` / `Shift+Enter` / `Alt+Enter` выполняют. В редакторе `Tab` принимает подсказку либо делает отступ, если подсказки нет. `?` открывает список сочетаний.
4. **Тип и удаление.** Значок `✂` удаляет ячейку, метка `py` / `md` показывает и меняет тип. Markdown отображает заголовки `##`, редактируется двойным щелчком и сворачивается подобно коду.
5. **Добавление Markdown.** Кнопка с исходной подписью `+ MD` создаёт Markdown-ячейку; существующая `+ Cell` также выбирает и фокусирует созданную ячейку.

Постоянное ядро, инструменты агента, сохранение/чтение `.ipynb`, выбор ядра, прогресс tqdm, переходы из трассировок, сворачивание длинного вывода и подсказка гибридного CPU унаследованы. В исходнике интерфейс на английском и китайском; локальная редакция добавляет русские тексты.

## Установка

Из GitHub, как в каталоге плагинов:

```bash
dsh plugin --profile desktop add github:NKUHan123/dsh-jupyterlab
```

Либо готовый архив из GitHub Release, без сборки:

```bash
dsh plugin --profile desktop add file:<path-to>/dsh-jupyterlab.tgz  # prebuilt tarball from the latest GitHub Release
```

После перезапуска DeepSeek Harness в сеансе появляется вкладка **Блокнот**. Перезапуск здесь описывает установочную процедуру и не выполняется автоматически при переводе документации.

В пакет входят готовый `lib/` и Python-драйвер. Сборка при установке не требуется: нет `prepare` или install-скриптов, которые pnpm должен одобрить.

> **Не устанавливать одновременно с `@beihaizb/dsh-notebook`.** Оба регистрируют одинаковые `nb_*`. Форк включает исходные возможности, поэтому сначала удалить исходный плагин:
> ```bash
> dsh plugin --profile desktop remove @beihaizb/dsh-notebook
> ```

Выбранному Python-окружению нужны `ipykernel`, `jupyter_client` и `nbformat`.

## Клавиатура

| Режим | Клавиша | Действие |
|---|---|---|
| Командный | `Enter` | Редактировать выбранную ячейку |
| Командный | `Esc` | Командный режим |
| Командный | `a` / `b` | Добавить выше/ниже |
| Командный | `d` `d` | Удалить |
| Командный | `↑` `↓` / `k` `j` | Предыдущая/следующая |
| Командный | `m` / `y` | Markdown/код |
| Командный | `Ctrl+Enter` | Выполнить, остаться |
| Командный | `Shift+Enter` | Выполнить, перейти к следующей |
| Командный | `Alt+Enter` | Выполнить, добавить ниже |
| Командный | `?` | Список сочетаний |
| Редактирование | `Ctrl+Enter` / `Shift+Enter` / `Alt+Enter` | Те же режимы выполнения |
| Редактирование | `Tab` | Принять дополнение либо сделать отступ |
| Редактирование | `Esc` | Выйти из редактирования |

## Инструменты, унаследованные из исходного проекта

`nb_new` / `nb_open` / `nb_save` / `nb_get` / `nb_context` / `nb_list` / `nb_list_vars` / `nb_inspect_object` /
`nb_add_cell` / `nb_delete_cell` / `nb_move_cell` / `nb_edit_cell` / `nb_edit_and_run_cell` /
`nb_cell_history` / `nb_revert_cell` / `nb_error_context` /
`nb_run_cell` / `nb_run_all` / `nb_apply_suggestion` /
`nb_kernel_restart` / `nb_kernel_restart_and_clear` / `nb_kernel_interrupt` /
`nb_kernel_list` / `nb_kernel_select` / `nb_clear_outputs` / `nb_set_cwd`

В этом форке `nb_add_cell` принимает также `before` для вставки перед указанной ячейкой.
