# dsh-jupyterlab

В DSH доступен блокнот с настоящим ядром Jupyter (`ipykernel` + `jupyter_client`). Переменные сохраняются между ячейками, изображения передаются через `display_data`, исключения показываются как traceback IPython. В браузере есть вкладка **«Блокнот»**; пользователь также может запускать ячейки вручную.

## Инструменты

| Инструмент | Когда использовать |
|---|---|
| `nb_get` | Сначала прочитать текущий блокнот: ячейки, вывод и состояние ядра |
| `nb_list` | Перечислить файлы `notebooks/*.ipynb` |
| `nb_new` | Создать пустой блокнот |
| `nb_open` | Открыть файл `.ipynb` |
| `nb_save` | Сохранить стандартный `.ipynb`; история замечаний хранится в `cell.metadata.dsh` |
| `nb_add_cell` / `nb_delete_cell` | Добавить или удалить ячейку |
| `nb_edit_cell` | **Целиком заменить** исходный код ячейки с сохранением версии |
| `nb_run_cell` | Выполнить ячейку кода в работающем ядре |
| `nb_run_all` | Выполнить ячейки сверху вниз, остановившись при ошибке |
| `nb_apply_suggestion` | Записать замечание пользователя об изменении |
| `nb_kernel_restart` / `nb_kernel_interrupt` | Перезапустить или прервать ядро |
| `nb_kernel_list` | Перечислить найденные локальные Python-ядра conda и наличие ipykernel |
| `nb_kernel_select` | Выбрать ядро по имени окружения, идентификатору или пути python.exe; вспомогательный процесс будет перезапущен |

## После нажатия «Передать ИИ для изменения» под ячейкой

В чате появится сообщение пользователя с префиксом `[notebook]`, идентификатором ячейки и её текущим кодом. Выполни весь цикл:

1. Измени эту ячейку через `nb_edit_cell`; в `reason` запиши замечание пользователя.
2. Сразу выполни её повторно через `nb_run_cell`.
3. Одним-двумя предложениями сообщи, что изменилось и прошёл ли запуск. При ошибке исправь её и выполни ячейку ещё раз.

Не заменяй работу с блокнотом отдельным независимым скриптом `.py`.

## Правила

- Перед изменениями вызывай `nb_get`, чтобы не изменить другую ячейку.
- Для графиков используй matplotlib и `plt.show()` либо `display(fig)`. Одного `savefig` недостаточно, если пользователь не просил сохранить изображение на диск.
- Состояние ядра сохраняется между ячейками: последующая ячейка может использовать переменные предыдущих.
- Сохраняй блокнот отдельно в `.py` только по просьбе пользователя о воспроизводимом самостоятельном скрипте. По умолчанию оставляй `.ipynb`.
